A standard-library Python program that forecasts GTA VI's launch-day Twitch viewership hour by hour: it pools the release-day curves of comparable past launches bundled in the case file, weights each by how closely its launch resembled this one (unlock pattern, platforms, audience scale, pre-launch profile), and reads each future hour's five quantiles off the weighted distribution of those launches' ratios to their own first hour.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
